# Data Model — ReverseCraftX (V1)

This document defines the relational database schema for ReverseCraftX, detailing entities, attributes, constraints, and relationships.


## 1. User
Represents any individual using ReverseCraftX.
* **Attributes:**
  * `id` (PK, UUID / Auto-increment ID)
  * `nom` (String)
  * `prenom` (String)
  * `email` (String, Unique)
  * `password_hash` (String)
  * `date_creation` (Timestamp)
* **Relations:**
  * Can publish multiple `Article`s (1:N)
  * Can write multiple `Comment`s (1:N)
  * Can save multiple `Article`s via `SavedArticle` (N:N)

---

## 2. Article
Represents a published design card visible in the platform library. (Note: The design metadata and title are directly integrated here to streamline the V1 model).
* **Attributes:**
  * `id` (PK)
  * `user_id` (FK -> User)
  * `title` (String)
  * `description` (Text, optional)
  * `date_ajout` (Timestamp)
* **Relations:**
  * Belongs to one author `User` (N:1)
  * Contains multiple `Image`s (1:N)
  * Receives multiple `Comment`s (1:N)
  * Can be saved by multiple users via `SavedArticle` (N:N)

---

## 3. Image
Represents an image uploaded or associated with an article.
* **Attributes:**
  * `id` (PK)
  * `article_id` (FK -> Article)
  * `url` (String / File path)
  * `date_ajout` (Timestamp)
* **Relations:**
  * Belongs to one `Article` (N:1)
  * Linked to one or more `Analysis` results (1:N)

---

## 4. Analysis
Represents the structured reverse-engineering insights generated by the AI based on an image (`UC-05`).
* **Attributes:**
  * `id` (PK)
  * `image_id` (FK -> Image)
  * `status` (Enum: `PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`)
  * `components` (JSON / Text)
  * `probable_materials` (JSON / Text)
  * `structure` (JSON / Text)
  * `hypotheses` (JSON / Text)
  * `manufacturing_steps` (JSON / Text)
  * `error_message` (Text, nullable)
  * `date_creation` (Timestamp)
  * `date_update` (Timestamp)
* **Relations:**
  * Associated with one `Image` (N:1)

---

## 5. Comment
Represents a user comment posted on an article (`UC-08`).
* **Attributes:**
  * `id` (PK)
  * `article_id` (FK -> Article)
  * `user_id` (FK -> User)
  * `contenu` (Text)
  * `date_saisie` (Timestamp)
  * `date_modification` (Timestamp, nullable)
* **Relations:**
  * Belongs to one `Article` (N:1)
  * Written by one `User` (N:1)

---

## 6. SavedArticle (Association Table)
Represents the bookmark / favorite relation between users and articles (`UC-06`, `UC-07`).
* **Attributes:**
  * `user_id` (PK/FK -> User)
  * `article_id` (PK/FK -> Article)
  * `date_enregistrement` (Timestamp)
* **Relations:**
  * Links `User` and `Article` in a Many-to-Many relationship.
